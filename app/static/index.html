        Health, runtime & ingest
        
GET/api/health
          
curl http://localhost:8000/api/health

        
GET/api/runtime
          
Port standard and default output endpoints.

          
curl http://localhost:8000/api/runtime

        
POST/api/ingest
          
Built-in HTTP webhook sink. Events appear in the live log.

          
curl -X POST http://localhost:8000/api/ingest -H 'Content-Type: application/json' -d '{"temp":21}'

        
GET/metrics
          
curl http://localhost:8000/metrics

      

      

        Sensors
        
GET/api/sensors
          
curl http://localhost:8000/api/sensors

        
POST/api/sensors
          
curl -X POST http://localhost:8000/api/sensors -H "Content-Type: application/json" -d '{"name":"temp-01","interval_sec":1,"running":true,"fields":[{"type":"timestamp","name":"ts"},{"type":"random_number","name":"t","min":18,"max":26}],"outputs":[{"type":"screen"}]}'

        
POST/api/sensors/{id}/start
          
curl -X POST http://localhost:8000/api/sensors/a1b2c3d4/start

        
POST/api/sensors/start-all
          
curl -X POST http://localhost:8000/api/sensors/start-all

      

      

        Examples, import, WebSocket, TCP
        
GET/api/examples
          
curl http://localhost:8000/api/examples

        
POST/api/examples/{id}/import
          
curl -X POST http://localhost:8000/api/examples/smart-building/import

        
GET/api/config/export
          
curl http://localhost:8000/api/config/export -o config.json
curl "http://localhost:8000/api/config/export?format=yaml" -o config.yaml

        

          
WebSocket ws://localhost:8000/ws. TCP ingress: localhost 5050.

          
echo '{"sensor":"ext-01","value":42}' | nc localhost 5050
