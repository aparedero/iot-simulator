▶Health & Metrics
GET/api/health

Returns server status, version, uptime and sensor count.

curl http://localhost:8000/api/health
{"status":"ok","version":"1.1.0","uptime_sec":42,"sensors":2,"max_sensors":100}
GET/api/metrics

Returns aggregate message/error counters and running count (JSON).

curl http://localhost:8000/api/metrics
GET/metrics

Prometheus text exposition format for scraping / observability stacks.

curl http://localhost:8000/metrics
# iotsim_messages_total 1234
# iotsim_sensors_running 3
# iotsim_sensor_messages_total{sensor_id="a1b2",name="temp-01"} 512
▶Example Scenarios
GET/api/examples

List bundled industry scenarios (smart building, GPS fleet, industrial machine, energy meter, air quality).

curl http://localhost:8000/api/examples
POST/api/examples/{id}/import

Load a bundled scenario. Add ?replace=true to wipe existing sensors first.

curl -X POST http://localhost:8000/api/examples/smart-building/import
▶Sensors CRUD
GET/api/sensors

List all sensors with their current status.

curl http://localhost:8000/api/sensors
POST/api/sensors

Create a new sensor. Returns 400 if name is duplicate or limit is reached.

curl -X POST http://localhost:8000/api/sensors \
  -H "Content-Type: application/json" \
  -d '{
    "name": "temp-01",
    "interval_sec": 1.0,
    "jitter_sec": 0.2,
    "running": true,
    "fields": [
      {"type":"timestamp","name":"ts","fmt":"iso"},
      {"type":"random_number","name":"temperature","min":18,"max":26,"decimals":2},
      {"type":"pattern_string","name":"device_id","pattern":"DEV-{d:4}-{seq}"}
    ],
    "outputs": [
      {"type":"screen","enabled":true},
      {"type":"mqtt","enabled":true,"host":"broker.hivemq.com","port":1883,"topic":"iot/sim/{sensor}"}
    ],
    "anomaly":{"enabled":false,"probability":0.05,"min_factor":1.5,"max_factor":3}
  }'
PUT/api/sensors/{id}

Replace a sensor's configuration. Same body as POST.

curl -X PUT http://localhost:8000/api/sensors/a1b2c3d4 \
  -H "Content-Type: application/json" \
  -d '{"name":"temp-01","interval_sec":2,"running":true,"fields":[...],"outputs":[...]}'
DELETE/api/sensors/{id}

Stop and delete a sensor. Returns 204.

curl -X DELETE http://localhost:8000/api/sensors/a1b2c3d4
▶Sensor Lifecycle
POST/api/sensors/{id}/start

Start a stopped sensor.

curl -X POST http://localhost:8000/api/sensors/a1b2c3d4/start
POST/api/sensors/{id}/stop

Stop a running sensor.

curl -X POST http://localhost:8000/api/sensors/a1b2c3d4/stop
POST/api/sensors/{id}/clone

Deep-copy a sensor with a unique auto-generated name. Clone is created stopped.

curl -X POST http://localhost:8000/api/sensors/a1b2c3d4/clone

▶Import / Export
GET/api/config/export

Download the current configuration. Add ?format=yaml for YAML.

curl http://localhost:8000/api/config/export -o config.json
curl "http://localhost:8000/api/config/export?format=yaml" -o config.yaml
POST/api/config/import

replace: true wipes existing sensors first. false merges (auto-renames conflicts).

curl -X POST http://localhost:8000/api/config/import \
  -H "Content-Type: application/json" \
  -d '{
    "replace": false,
    "sensors": [ { "name":"imported-1", "interval_sec":1, ... } ]
  }'
POST/api/config/import-raw

Import a raw JSON or YAML document (auto-detected). Add ?replace=true to wipe first.

curl -X POST "http://localhost:8000/api/config/import-raw?replace=true" \
  -H "Content-Type: text/plain" --data-binary @config.yaml
▶WebSocket /ws

Connect to ws://<host>:8000/ws. The server pushes JSON events. The last 200 events are replayed on connect.

// Event shapes:
{"type":"sample","sensor_id":"…","sensor_name":"…","payload":{…},"targets":[…],"count":42,"errors":0}
{"type":"created","sensor_id":"…","sensor_name":"…"}
{"type":"updated","sensor_id":"…","sensor_name":"…"}
{"type":"deleted","sensor_id":"…","sensor_name":"…"}
{"type":"error","sensor_id":"…","sensor_name":"…","message":"…"}
{"type":"ingress","source":"tcp:1.2.3.4:5050","payload":{…}}
// JavaScript example:
const ws = new WebSocket("ws://localhost:8000/ws");
ws.onmessage = (e) => console.log(JSON.parse(e.data));
▶TCP/JSON Ingress :5050

Send newline-delimited JSON to port 5050; events appear in the live log.

echo '{"sensor":"ext-01","value":42}' | nc localhost 5050
